# Event contract documentation design

## Document Location

Add `docs/DAEMON_EVENTS.md` as the canonical user/developer documentation for
daemon event contracts. Link it from README's "Local Runtime API" section.

## Coverage

The document should cover two event surfaces:

- `/events`: daemon-wide replayable EventBus SSE.
- `/message` streaming: per-request SSE generated by `sseEventHandler`.

It should also clarify related observability surfaces:

- run records and structured events
- metrics and traces
- local-only replay/export behavior

## Verification

Use a lightweight Go static documentation test in `internal/daemon/webui_test.go`
or another daemon test file. The test should read `docs/DAEMON_EVENTS.md` and
README, asserting the contract includes key event names and replay terms.

## Scope Boundary

No runtime behavior changes are required. This child is documentation plus
static tests only.
